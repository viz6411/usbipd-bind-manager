# usbipd-bind-manager

Интерактивный консольный менеджер для быстрого управления пробросом USB-устройств из Windows 11 в WSL2 (или удалённые Linux-машины) через `usbipd-win`.

## Зачем это нужно

При работе с WSL2 часто требуется временно пробрасывать физические USB-устройства внутрь Linux — например, аппаратные токены безопасности (YubiKey, Token2, Rutoken), смарт-карты, отладчики или микроконтроллеры — а затем возвращать их обратно в Windows.

Стандартный сценарий требует каждый раз открывать терминал от имени администратора, выполнять `usbipd list`, запоминать меняющийся `BUSID` и вручную вводить команды `usbipd bind` / `usbipd unbind` (особенно если в WSL запущен фоновый цикл с `--auto-attach`, где простого `detach` недостаточно).

**`usbipd_manager.cmd`** автоматизирует эту рутину в один клик:
* Запускается двойным кликом и сам запрашивает права администратора, сохраняя современный интерфейс **Windows Terminal**.
* Показывает наглядный список всех USB-устройств и их текущий статус (`ПОДКЛЮЧЕНО` / `Не подключено`).
* Формирует динамическое меню действий (скрывает недоступные пункты).
* Позволяет подключать (`bind`) и отключать (`unbind`) как одно, так и сразу несколько устройств по их порядковым номерам (например: `1 3` или `1, 2`).
* После каждой команды перепроверяет реальный статус устройства в системе и обновляет меню для дальнейшей работы.

## Установка зависимостей

Для работы скрипта в системе должна быть установлена утилита **[usbipd-win](https://github.com/dorssel/usbipd-win)**. Если она ещё не установлена, выполните в PowerShell или командной строке:

```powershell
winget install --interactive --exact dorssel.usbipd-win
