# usbipd-bind-manager

Интерактивный консольный менеджер для Windows 11, упрощающий управление разрешениями проброса USB-устройств (`bind` / `unbind`) через [`usbipd-win`](https://github.com/dorssel/usbipd-win).

> **Важно:** Утилита управляет именно **разрешением шаринга** устройств на стороне хоста Windows (`bind` и `unbind`), переводя их в состояние `Shared` для последующего подключения любым USB/IP-клиентом (виртуальными машинами, удалёнными хостами, WSL и др.). Непосредственное монтирование (`attach`) выполняется на стороне клиента.

---

## Возможности

- **Наглядная таблица устройств** в Windows Terminal со скруглёнными рамками и цветовой индикацией статусов:
  - `● Attached` *(зелёный)* — шаринг разрешён, устройство активно захвачено USB/IP-клиентом.
  - `◐ Shared` *(бирюзовый)* — шаринг разрешён (`bind`), устройство готово к подключению клиентом.
  - `○ Not shared` *(серый)* — шаринг запрещён, устройство доступно только в Windows.
- **Точечное и массовое управление:**
  - `[1]` **Разрешить проброс (`bind`)** — выбор конкретного устройства по номеру или `[A]` для всех свободных (`Not shared`).
  - `[2]` **Запретить проброс (`unbind`)** — выбор конкретного устройства по номеру или `[A]` для всех активных (`Shared` / `Attached`).
  - `[3]` **Обновить состояние** — повторный опрос `usbipd list` и перерисовка таблицы в реальном времени.
  - `[0]` **Выход** — завершение работы.
- **Автоматическое повышение привилегий (UAC):** при запуске от обычного пользователя скрипт сам запрашивает права администратора (необходимые для `usbipd bind/unbind`) и перезапускается во вкладке **Windows Terminal** (`wt.exe`), корректно обрабатывая пути с пробелами и кириллицей. При отсутствии `wt.exe` используется стандартная консоль `cmd.exe`.
- **Один файл без внешних зависимостей:** логика парсинга и отрисовки на PowerShell встроена напрямую в `usbipd_manager.cmd`.

---

## Требования

- **Windows 10 / 11**
- **usbipd-win** (установка через `winget`):
  ```powershell
  winget install --interactive --exact dorssel.usbipd-win
  ```
- **Windows Terminal** *(рекомендуется — предустановлен в Windows 11)* для корректного отображения псевдографики и цветов.

---

## Установка и запуск

1. Скачайте файл `usbipd_manager.cmd` или скопируйте его содержимое в локальный файл (обязательно в кодировке **UTF-8**).
2. Запустите `usbipd_manager.cmd` двойным кликом или из терминала.
3. Подтвердите запрос UAC на запуск от имени администратора.

## Устранение неполадок

- **«Кракозябры» вместо кириллицы или рамок:** убедитесь, что файл `usbipd_manager.cmd` сохранён в кодировке **UTF-8** (не `Windows-1251` / `CP866`).
- **Скрипт не видит новые подключённые флешки/токены:** выберите пункт `[3]` в главном меню, чтобы заново опросить шину USB через `usbipd list`.
